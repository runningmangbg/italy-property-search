# Italy Property Search

A project for collecting, comparing, and tracking property listings in Abruzzo and Marche, Italy.

## Planned features

- Keep property listings and source links in one place.
- Compare and rank properties against search criteria.
- Monitor asking prices and price reductions.
- Record comments and track shortlisted or closed properties.
- Provide a shared web interface for reviewing candidates.

## Project status

Initial repository setup is in progress. Application code and deployment configuration have not been added yet.
